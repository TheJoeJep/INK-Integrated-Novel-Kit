# Problem → Technique Index

**The diagnostic layer.** Start from the symptom, not the solution.

**How to use it:** readers report symptoms reliably and diagnose causes badly. Take the *location*
of a complaint seriously and treat the prescription as one hypothesis. Work down each row's
causes in order — they're ordered by base rate, most common first.

## The three questions to ask first

Before consulting anything above, on any problem:

1. **What did this promise, and did it pay?**
2. **What does this character want, and does it show?**
3. **What progressed here, and can the reader see it?**

Most problems in a manuscript are one of these three, and most of the rest are downstream of
them.
